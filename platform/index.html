( 01 / 06 ) Architecture

Models decide. Agents manage.

Media buying happens at two very different speeds.

System 1

Models make the instant decisions.

Every impression needs a decision in milliseconds.

Small, purpose-built models run directly in the bidstream and answer questions such as:

  1. 01Should we bid?
  2. 02What is this impression worth?
  3. 03How likely is it to convert?
  4. 04Is this inventory high quality?
  5. 05What should we pay?

They are fast, predictable and built for one job.

Model → decision → bid

Milliseconds.

System 2

An agent manages the campaign over time.

Campaigns run for days, weeks or months.

Counter gives each campaign an always-on agent that can:

  • monitor performance
  • investigate changes
  • adjust budgets
  • run experiments
  • train and deploy models
  • ask for approval

Use Counter’s agent or bring your own.

Agent → observe → decide → act → repeat

Always running.

( 02 / 06 ) Models

Open models.

You don’t need a data science team to experiment with custom decisioning.

01Start with an open model.

Counter provides an open family of AdTech System One Models for common media problems.

ConversionEstimate the likelihood of an outcome.
AttentionEstimate the quality of an impression or placement.
QualityScore the environment in which an ad appears.
ContextualUnderstand the relationship between an impression and a campaign.
Bid pricingEstimate what an impression is worth.
IncrementalityEstimate whether an impression creates an outcome that would not otherwise happen.

The models are open source. Use them as they are, change them, or build your own on top.

02Fine-tune it on your data.

Counter provides infrastructure to train and fine-tune models on your own campaign and outcome data, with the whole lifecycle in one place.

  1. 01Data
  2. 02Train
  3. 03Evaluate
  4. 04Shadow
  5. 05Deploy
  6. 06Monitor

Your trained models remain yours.

03Combine models.

A media decision doesn’t have to come from one black-box algorithm. A single bid can draw on several models at once:

Advertiser model × Agency model × Publisher model × Open model ↓ Bid decision

Models can be private, shared, open source or commercial. Counter is the ecosystem for portable media intelligence.

( 03 / 06 ) ARTF

Built on ARTF.

Your model / bidder ↓ ARTF container ↓ Host platform ↓ OpenRTB ↓ Publisher supply

Counter is built on ARTF, the IAB Tech Lab open standard for running software inside the programmatic bidstream.

Package decisioning once and run it inside supporting host infrastructure, close to the auction.

Counter builds on the industry standard rather than creating a proprietary execution format.

  • Fewer hops
  • Less unnecessary compute
  • Lower latency
  • Lower cost
  • Lower carbon

Read the ARTF standard from IAB Tech Lab
