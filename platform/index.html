( 01 / 14 ) Architecture

Two systems. Two jobs.

Media buying happens at two very different speeds.

System 1

Models make the instant decisions.

Every impression needs a decision in milliseconds.

Small, purpose-built models run directly in the bidstream and answer questions such as:

  1. 01Should we bid?
  2. 02What is this impression worth?
  3. 03How likely is it to convert?
  4. 04Is this inventory high quality?
  5. 05What should we pay?

They are fast, predictable and built for one job.

Model → decision → bid

Milliseconds.

System 2

An agent manages the campaign over time.

Campaigns run for days, weeks or months.

Counter gives each campaign an always-on agent that can:

  • monitor performance
  • investigate changes
  • adjust budgets
  • compare models
  • run experiments
  • retrain models
  • review supply
  • diagnose underdelivery
  • produce reports
  • ask for approval when needed

Use Counter’s agent or bring your own.

Agent → observe → decide → act → repeat

Always running.

( 04 / 14 ) ARTF

Built on an open standard.

ARTF

Counter is built on ARTF — the Agentic Real Time Framework from IAB Tech Lab.

ARTF provides a standard way to run containerised software inside the infrastructure where programmatic auctions happen.

Instead of sending every auction through another external system, decisioning happens close to the bidstream.

Counter model / bidder ↓ ARTF container ↓ Host infrastructure ↓ OpenRTB auction ↓ Publisher supply

ARTF gives the industry a shared way to package and run this logic rather than requiring every platform to invent a different proprietary integration.

Counter builds on that standard rather than replacing it.

( 08 / 14 ) Agents

Campaigns that keep running.

The real-time model makes the individual decision.

The agent looks after everything around it.

You can give an agent a simple instruction:

Instruction
Check this campaign every morning. If CPA rises by more than 15%, investigate why. Make small budget changes automatically, but ask me before changing the model or increasing total spend.

Or:

Instruction
Test the new store-visit model against the current model. Keep 80% of spend on the existing model until there is enough evidence to compare them.

The schedule keeps running without an open chat window.

Rules and approvals remain explicit.

The agent acts within the permissions you give it.

( 10 / 14 ) Supply

Buyers and publishers connect directly.

( 12 / 14 ) Logs

Inspect every decision.

For any auction, you can see exactly what happened.

For example:

Opportunity ↓ Features ↓ Models used ↓ Model scores ↓ Decision ↓ Bid ↓ Auction result ↓ Outcome

And for the campaign around it:

Agent observation ↓ Reason for change ↓ Action ↓ Approval, if required ↓ Result

This is not just transparency at reporting time.

It is traceability from campaign objective down to an individual decision.
